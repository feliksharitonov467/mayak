Новая награда

Импорт операций

Вставь операции в формате JSON — массив объектов. Можно получить его от ИИ по скриншотам банка (пример под полем).

Показать формат и подсказку для ИИ
Каждая операция: type («expense» или «income»), amount (число), category (текст), date («ГГГГ-ММ-ДД»), note (необязательно).
Промпт для ИИ: «Распознай траты со скриншота и верни JSON-массив объектов с полями type, amount, category, date, note. type всегда expense для трат. Категории выбери из: Еда, Транспорт, Развлечения, Учёба, Спорт, Здоровье, Одежда, Подарки, Подписки, Непредвиденное, Другое.»

Добавить блюдо

Цели по питанию (в день)

Оставь 0, если какой-то показатель отслеживать не нужно.

Мои блюда

Сохранённые блюда. Нажми, чтобы добавить в выбранный приём пищи.

Импорт еды за день

Опиши ИИ, что ел за день, попроси вернуть JSON — и вставь сюда. У каждого блюда можно указать приём пищи (meal), и сайт сам разложит по завтраку/обеду/ужину.

Показать формат и промпт для ИИ
Каждое блюдо: meal (приём пищи), name (текст), calories, protein, fat, carbs (числа), cost (₽, необязательно), note (необязательно).
Значения meal: breakfast (завтрак), snack (перекус), lunch (обед), dinner (ужин), extra (дополнительно). Если не указать — попадёт в выбранный выше запасной приём.

Промпт для ИИ: «Вот что я ел за день: [опиши приёмы пищи и порции]. Для каждого блюда определи приём пищи и оцени КБЖУ. Верни JSON-массив объектов с полями meal, name, calories, protein, fat, carbs, cost, note. Поле meal — одно из: breakfast, snack, lunch, dinner, extra. Если приём непонятен — ставь extra. Только JSON, без пояснений.»
